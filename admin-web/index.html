No Server Needed

Your entire website lives inside the admin-web/ folder with zero build tools required. Publish it free in under 60 seconds:

1. Firebase Hosting (Recommended)

Pre-configured in firebase.json! Google Sign-In works immediately with zero domain setup.

firebase deploy --only hosting --project gen-lang-client-0124044841

2. Netlify Drop (Drag & Drop)

Open app.netlify.com/drop, drag the admin-web folder, and add your Netlify hostname under Firebase Console → Auth → Authorized Domains.

3. GitHub / Cloudflare Pages

Push repo to GitHub and publish the admin-web folder on Cloudflare Pages or GitHub Pages for free global CDN + HTTPS.
